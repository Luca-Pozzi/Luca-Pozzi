# About me 👋

I’m a PhD student in Mechanical Engineering at Politecnico di Milano (WE-COBOT lab), with a M.Sc. in Biomedical Engineering.
My research focuses on human-robot interaction and socially assistive robots for older adults in long-term care.
I build robot applications with Python and ROS, including conversational agents based on speech recognition and LLMs.

📍 Lecco, Italy
